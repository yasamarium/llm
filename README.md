# Qwen 4B - AS Cloud

A minimalist, iOS 18-themed web chat application for **Qwen3 4B**, designed for zero-config 1-click deployment on **Vercel** and powered by **AS cloud**.

---

## Features

- ⚡ **120fps Fluidity**: Hardware-accelerated transitions and frame-rate optimized typewriter streaming.
- 🖤 **Monochrome Luxury**: Pure black and white Cupertino aesthetic, frosted glass dynamic island, and zero visual clutter.
- 🟢 **AS Cloud Live Status**: Real-time status pill indicating live connection to AS cloud.
- 🚀 **Zero Configuration**: Connects directly to AS cloud out of the box with zero setup.

---

## 🚀 Deployment on Vercel

1. Open [Vercel Dashboard](https://vercel.com/new).
2. Select **Import** next to `yasamarium/llm`.
3. Click **Deploy**. Everything runs directly out of the box!
