AS Cloud Encryption Vault API

1. Encrypt and Save to Database (POST /api/vault)
curl -X POST "https://asllm.vercel.app/api/vault?action=encrypt" \ -H "Content-Type: application/json" \ -d '{ "text": "Secret note to protect", "key": "OptionalPassword123", "title": "My Note", "store": true }'
2. Decrypt Record by ID or Token (POST /api/vault)
curl -X POST "https://asllm.vercel.app/api/vault?action=decrypt" \ -H "Content-Type: application/json" \ -d '{ "id": "asv_m89_abc", "key": "OptionalPassword123" }'
3. List Stored Vault Records (GET /api/vault?action=list)
curl -s "https://asllm.vercel.app/api/vault?action=list"
